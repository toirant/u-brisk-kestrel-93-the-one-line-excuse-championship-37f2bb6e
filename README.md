## How it works

`main.py` (Python 3, no dependencies) writes the one-line excuse to `/output/entry.txt`, then reads it back and verifies the gate: UTF-8 text, 1 to 140 characters, a single line, not only whitespace.

Run it:

```sh
python3 main.py
```
